TO RUN ON VS CODE WITH VENV ENVIROMENT:-
1. Make sure Python 3.10+ is installed
2. Open the folder in VS Code
3. Open the vs terminal and run these commands:

   python -m venv venv
   venv\Scripts\activate
   pip install groq
   python classifier.py

4. Results will appear in the terminal

TO RUN ON JUPYTER WITH ANACONDA ENVIROMENT - 

1. Make sure Anaconda is installed
2. Open Command Prompt and run:

   jupyter notebook

3. Navigate to the llm_extraction folder
4. Click on classifier_task.ipynb

Information Extraction Task Summary:

This script was developed using Visual Studio Code with a Python virtual environment (venv) for local development, and also tested on Jupyter Notebook via Anaconda locally. It uses the LLaMA 3.3-70B model via the Groq API to extract five structured entity types from English text: Person, Organization, Location, Date, and Event. The model reads each sentence and returns the extracted fields in a fixed format, writing N/A when a field is not found. The extraction worked accurately across all 5 samples, correctly identifying names, companies, places, and dates.A limitation is that the model may struggle with informal sentences that lack clear named entities and this would result in an inaccurate output.
